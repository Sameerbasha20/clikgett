# 🛒 ClikGett

A high-performance Flutter-based eCommerce application with modern UI, Firebase integration, secure payments, and efficient state management. ClikGett is designed to offer users a smooth and intuitive shopping experience with optimized performance and clean architecture.

---

## 🧾 Description
**ClikGett** is a Flutter eCommerce solution packed with essential features like product browsing, cart, wishlist, authentication, and real-time database interactions. Built on the latest stable Flutter SDK, it ensures smooth animations, responsiveness, and scalability.

---

## ✨ Features

- 🔐 **Authentication & User Management**  
  Firebase Auth with Email/Password login

- 📦 **Product Management**  
  Product listing, detail page, cart, wishlist, and checkout system

- 📲 **Push Notifications**  
  Real-time messaging with Firebase Cloud Messaging

- 📊 **State Management**  
  Efficient and lightweight using Provider

- 📷 **Image Optimization**  
  Cached images, lazy loading, and fast UI rendering

- 🌐 **Connectivity**  
  Detects online/offline states and handles gracefully

- 💸 **Payment Gateway Ready**  
  Razorpay integrated for smooth payment experience
