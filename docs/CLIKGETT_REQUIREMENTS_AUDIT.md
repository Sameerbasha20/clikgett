## 1. Classification Methodology & Status Tiers

Every requirement is audited against the active codebase, database schema, and live AWS RDS configuration, classified into one of 7 official tiers:
1. **ALREADY IMPLEMENTED + DYNAMIC:** Fully functional, database-backed, API-backed, and UI-connected.
2. **ALREADY IMPLEMENTED BUT STATIC/HARDCODED:** Logic/structure exists, but currently relies on hardcoded constants or outdated configuration rows.
3. **PARTIALLY IMPLEMENTED:** Part of the workflow exists (e.g., partial DB or partial controller), but lacks end-to-end integration or specific required sub-features.
4. **BACKEND EXISTS BUT UI MISSING:** Database schema and backend REST endpoints are functional, but Admin or User/Delivery frontend UI is absent.
5. **UI EXISTS BUT BACKEND/DB MISSING:** Frontend screens/widgets exist, but lack database persistence or real backend APIs.
6. **NOT IMPLEMENTED:** No database table, API, or UI exists for the requirement.
7. **BLOCKED BY EXISTING DATABASE/API STRUCTURE:** Architectural blocker prevents implementation without structural refactoring.

*(Note: Requirement #11 has been removed per project instructions and is marked N/A).*

## 3. Immediate Implementation Plan (Phase 2 Roadmap)

Following the audit, the required implementations will be sequenced with priority on backend financial safety, followed by Admin configuration, and client application integrations:

1. **Database Schema Enhancements:**
   - Add `DisplayOrder` to `SubCategories`.
   - Update `Settings` row `Minordervalue_wallet` to `399`.
   - Add `CategoryID` to `product_restrictions` and configure category 23 (Atta) as coupon-excluded.
   - Add `LongDistanceFeeEnabled`, `LongDistanceThresholdKm`, `LongDistanceFee`, `LargeCartThreshold1Items`, `LargeCartThreshold1Minutes`, `LargeCartThreshold2Items`, `LargeCartThreshold2Minutes`, `CashbackMode`, `DeliveryAddressVisibility`, `DeliveryProductListVisibility` to `AdminShopToggleSettings`.
   - Add `DestinationType` and `DestinationID` to `Banners`.
   - Add `StartDate`, `EndDate`, `Description`, `ImageUrl`, `DisplayOrder` to `HomepageSections`.
   - Create `SearchLogs`, `OrderETAAdjustments`, `CashbackPending`, `product_unlocks`.

2. **Backend Services & Controllers:**
   - Update `PricingEngine.js`: Category-level restriction check (Atta coupon exclusion), Long-distance fee calculation, Large-cart additional delivery time calculation, Product unlock validation.
   - Update `AdminOrders.js`: Advanced filtering & sorting for past orders, ETA adjustment audit logging (+5/+10/+15 min), Item-level order adjustments (remove unavailable item with recalculation and notification).
   - Update `DeliveryBoy.js`: Obscure/omit customer address and product items when Admin toggle is OFF.
   - Update `Banners.js` & `SubCategories.js`: Reorder API and banner destination routing.
   - Update `Users.js` & `AdminUsers.js`: Comprehensive customer details API (addresses, wallet ledger, rewards, heartbeat) and temporary home section date filtering.
   - Create `AdminCostOverview.js`: Secure AWS Cost Explorer endpoint with IAM error handling.
   - Create `ProductUnlocks.js`: CRUD and active unlock suggestions.
   - Create `Forms.js`: Feedback admin management.

3. **Admin Dashboard UI:**
   - Settings page updates: Wallet min order (399), Long-distance delivery fee, Large-cart delivery thresholds, Cashback mode (Auto/Manual), Delivery app visibility toggles.
   - Orders page updates: Multi-filter & sort bar for past orders, Order details timeline with timestamps, ETA adjustment buttons (+5, +10, +15 min), Unavailable product removal dialog.
   - Customer Details page overhaul: Tabs for Profile, Addresses, Orders, Wallet ledger, Rewards, Device info.
   - Subcategories page: Drag/order reordering controls.
   - Banners page: Destination selector (SubCategory).
   - New Admin pages/tabs: Feedback inbox, Search Analytics, Temporary Home Sections, Product Unlocks, AWS Cost Overview.

4. **User & Delivery App Integrations:**
   - Flutter UserApp: Centered bottom floating cart capsule widget, Coupon suggestions bar ("Add ₹X more"), Atta coupon exclusion server error handling, Feedback form, Milestone progress screen, Clickable banners navigation to subcategory, Scheduled order time slots, Product unlock banner.
   - Delivery Android App: Honor backend address and product list masking when Admin toggles are disabled.
